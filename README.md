# 📄 PDF to Markdown Token Optimizer

**A sleek, privacy-first web utility that strips visual bloat from PDFs and converts them into clean, structured Markdown.**
*Built specifically to optimize text documents, academic papers, and code snippets for maximum token efficiency in LLM chats.*

**Fast. Local. Layout-Aware. Fully Offline Ingestion.**

---

## ✨ Key Features

* **🧠 Token-Thrifty Workflows:** Converts heavy multi-page PDFs into lightweight Markdown, cutting down your context window usage by 30% to 70% per upload.
* **🔬 Advanced Layout Profiles:** Built-in heuristics optimized for different document structures:
  * **Default:** Balanced text reconstruction and cleanup.
  * **Academic Article:** Higher tolerance for multi-column splits and subtle font metrics to prevent text bleeding across column gutters.
  * **Slides / Handouts:** Preserves layout boundaries and automatically inserts slide separators.
  * **Scan-Heavy / OCR-First:** Forces local engine text extraction for unreadable documents.
* **🇮🇱 Bilingual Hebrew & English Support:** Automatically detects right-to-left (RTL) Hebrew text and correctly aligns the bidirectional rendering order so code and text mix perfectly.
* **📦 Multi-File Batching:** Upload up to 5 files simultaneously. Download converted files individually or compile them all into a single structured `.zip` archive.
* **🛡️ Privacy First:** Your data never leaves your infrastructure. All extraction and formatting processing occurs completely locally in-memory.
